# Check if the object is a [parquetMDB](https://patzaw.github.io/TKCat/reference/parquetMDB.md) object

Check if the object is a
[parquetMDB](https://patzaw.github.io/TKCat/reference/parquetMDB.md)
object

## Usage

``` r
is.parquetMDB(x)
```

## Arguments

- x:

  any object

## Value

A single logical: TRUE if x is an
[parquetMDB](https://patzaw.github.io/TKCat/reference/parquetMDB.md)
object
